# UNIVERSAL LAWS

*(v1.0 — 2026-08-06, born of the Tower audit. One law per line, one reason
per law. These apply across every ACP project regardless of stack; Genesis
Phase R deliverable #1 harvests this file into each project's CLAUDE.md
stub.)*

- **Cache-bust (`?v=`) on every CSS/JS lap.** Browsers cache aggressively;
  without a version bump the Commander's eye can grade a stale asset and
  certify a change that never actually shipped to the screen.
- **Band-walk 768/900/1024/1200/1440/1920 on composition laps.** Layout
  breaks hide between named breakpoints, not at them; walking the full
  band is the only way to catch a collapse before a real visitor does.
- **Honest facades.** Every non-functional UI action routes to a real
  destination — a decorative dead link is still a lie, and lies erode the
  trust the whole doctrine runs on.
- **Raw GitHub pulls as certification gold standard (SHA-pinned).** A
  rendered preview can lag the commit that produced it; a raw pull at a
  named SHA is the only artifact that cannot drift out from under a
  certification.
- **Runtime behavior verified only on the Commander's device.** File
  integrity and rendered behavior are different claims; no amount of raw
  pulling substitutes for the Commander actually looking at the live
  thing.
- **Anchors name their search domain.** An anchor without a declared
  scope invites a false "matched exactly once" — the same string can be
  unique in one file and repeated in the tree it actually governs.
- **`tokens.css` single-source.** Design values duplicated across files
  drift the moment one copy gets edited and the other doesn't; a single
  source is the only way the drift becomes impossible instead of just
  unlikely.
- **The Key Pre-Flight Law.** Before any ignition key fires, every
  factual assumption the key makes is certified against ground
  truth — not only its anchors. An anchor that matches proves one
  string exists; it proves nothing about the assumptions written
  around it. Three case studies from Campagne FORMULAIRE
  (2026-08-19, hotico-proto): a key ordered "keep the existing
  prototype note" on a page that had none (LEDGER entry #51,
  DEVIATION FLAGGED); the phrase "both consumer pointers" let a
  third consumer drift three versions stale before a Tribunal
  enumerated (entry #54); and the F-3 key's manifest declared five
  files while its own DOs required six — caught at execution,
  resolved by the executor, recorded in the acp-doctrine LEDGER
  entry that codified this law.
- **Consumer lists are enumerated, never remembered.** Any law that
  says "every consumer" (cache-bust above all) is satisfied only by
  a grep across the tree at key-cut time. A consumer list carried in
  a head — any head, Tower included — is how `in-curand.html` served
  stale CSS three versions deep before anyone thought to enumerate
  (hotico-proto, entry #54).
- **Manifests derive from the DOs.** A key's file manifest is
  computed from what its instructions touch, never authored beside
  them. Two lists describing one truth will disagree eventually, and
  the executor — not the author — inherits the contradiction.
- **The pulse marks the boundary.** Every campaign close triggers a
  campaign-scoped pulse before the next campaign opens: shipped,
  laws tightened, open gates, queued next. A campaign that ends
  without a pulse leaks its lessons into chat history, where laws go
  to be forgotten.
